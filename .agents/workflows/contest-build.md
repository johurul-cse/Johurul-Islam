# Contest Build Workflow

Use this workflow after receiving the contest problem.

## 1. Understand
Extract:
- problem goal
- users
- inputs
- outputs
- MUST-HAVE tasks
- BONUS tasks
- constraints
- sample data

## 2. Scope
Classify:
- MUST HAVE
- SHOULD HAVE
- BONUS

Choose the smallest reliable architecture.

## 3. Architecture
Define:
- frontend stack
- pages/components
- browser storage if needed
- external API usage if needed
- translation structure

Avoid backend architecture because the contest is frontend-only.

## 4. Build MVP
Create the smallest complete working user journey.

## 5. Verify
Run the app and test:
- primary flow
- required features
- invalid input
- empty state
- loading state
- error state
- browser persistence
- Bangla/English

## 6. Polish
Improve visual hierarchy, spacing, typography, responsive behavior and feedback.

## 7. Deploy
Deploy to a public HTTPS static host and verify the live URL.

## 8. Finalize
Update README and LICENSE.
Make the required final commit and push before T+90.
Run the final review checklist.
